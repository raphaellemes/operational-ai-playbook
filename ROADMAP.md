# Roadmap

This roadmap is intentionally lightweight. The goal is to keep the repository useful, practical, and easy to contribute to.

## v0.1 - Initial Playbook

Status: done.

- Core README
- Process before AI
- RAG governance
- Agent boundaries
- Criticality matrix
- Decision logs
- Templates
- Fictional examples
- Small Python demo

## v0.2 - More Operational Examples

Focus: make the playbook easier to apply in different domains.

Planned examples:

- finance operations;
- customer experience;
- field service;
- quality monitoring;
- sales and CRM;
- knowledge management;
- internal policy assistant.

## v0.3 - Diagrams And Visual Architecture

Focus: make the ideas easier to understand and reuse.

Planned additions:

- RAG governance flow diagram;
- agent escalation flow;
- criticality-to-controls map;
- decision log lifecycle;
- process-before-prompt diagram.

## v0.4 - Interactive Demo

Focus: create a small demo that shows the method in action.

Possible directions:

- Streamlit demo;
- CLI decision classifier;
- JSON schema validation;
- synthetic dataset;
- example audit log viewer.

## v0.5 - Bilingual Templates

Focus: make the project useful in English and Portuguese.

Planned additions:

- Portuguese README;
- translated templates;
- translated contribution guide;
- examples with Portuguese operational language.

## Open Questions

- Should the project stay documentation-first or evolve into a small toolkit?
- Which domains need the best first examples?
- Should decision logs have a JSON Schema?
- Should RAG source governance have a machine-readable format?
- How much code is enough without making the repo too technical?
